# 非占位替换：资料从哪来、这一步改了什么

打击器「这一击翻不翻」和轨道 \(N_{\mathrm{SEU}}\) 不是同一条公式。下面按你列的三件事写：能引用的已经接到代码；缺口写明去哪填，不编数字。

## 1 打击器「这一击翻不翻」——有文献，已替换

手册 M9 建议式（单位必须一致）：

\[
\mu_d = \mathrm{bits}_d\cdot\sigma_d(\mathrm{LET})/A_{\mathrm{kernel}},\qquad
N\sim\mathrm{Poisson}(\mu),\qquad
P(\ge 1)=1-e^{-\mu}
\]

- \(\sigma_d(\mathrm{LET})\)：Lee et al., REDW 2014, DOI `10.1109/REDW.2014.7004595`，JSON `data/weibull_7series_measured.json`。\(\sigma\) 是 **cm²/bit**。
- \(A_{\mathrm{kernel}}\)：必须也是 **cm²**（µm² × 10⁻⁸）。交接稿里若写成 \(A\) 用 µm²、\(\sigma\) 用 cm²，会错 10⁸。
- 查看器默认：`kernel_model=anchored`（WP8，Radaelli 簇面积量级）+ `flip_model=weibull`。不再用 `P_DEFAULT = 0.30/0.35/0.40/0.45`。
- `P_DEFAULT` 仍留在 `domains.py`，只给 `flip_model=bernoulli` 的回归/几何调试。下拉框可选回去。
- DSP 在 Lee Table 1 **没有行**：weibull 路径 σ=`None`，**永不翻 DSP**。这是缺口，不是 0.45 硬币。
- anchored 核面积约几 µm²，单次打击翻转会很少。那是 σ 和核面积对上之后的物理结果。若仍用 legacy `a0=12` 格子核，\(A\) 大两个数量级，\(P\) 会接近 0。

## 3 其余占位：这一步改了什么、什么还改不了

| 项 | 以前 | 现在 | 来源 |
|---|---|---|---|
| `P_DEFAULT` 驱动 GUI | 0.30/0.35/0.40/0.45 | GUI 默认 Lee σ；硬币只作选项 | Lee 2014 |
| SLICE CFG=400 + 8×primitives | 发明 | **2122** = UG470 bitstream 229,878,496 / UG474 slices 108,300 | 均匀摊到每个 slice，**不是 essential bits** |
| BRAM 36864 | 已接近真实 | **36×1024**，明确 RAMB36E1 | DS180 / UG473 |
| DSP 96 | 发明 | **169** = UG479 A+B+C+D+P 位宽 | 占用几何；无 DSP σ |
| `n_bits=1`（weibull） | 占位重数 | Poisson(\(\mu\))，上限为该 Site 位数 | 与 M9 同一 \(\mu\) |
| 椭圆核 / RPM 8 µm | assumption | **仍是 assumption** | UG474/DS180 **不发布** RPM 节距。区间 4–16 µm 写在 `units.py`。没有官方数就不能改成「实测 8」 |
| CFG 码字 `proxy` | proxy | **仍是 proxy** | 需要 bitstream / SEM essential bits。Vivado 授权 + `bitgen`/`readback` 才能换 |
| Weibull JSON 躺着 | 未接线 | `layout_ecc/weibull.py` 加载并驱动 `flip_model=weibull` | M9 |

码字和 RPM 不是「再搜一篇论文就能填」：前者是本设计的 bitstream，后者是厂商未公开的版图节距。
