# 布局感知 ECC 仿真平台：理论内核凝练

## 0. 为什么建这个平台

写算法防护论文时，必须对软错误的物理行为做假设：哪些地方已经防护好了、哪些地方值得防护、一次打击最多影响几个单元。不了解这个过程，假设就是猜测——有时猜对，有时猜错，而作者自己不知道哪些是对哪些是错。

这个平台的目的不是产出更多数字，而是建立**假设判断力**：

- **哪些假设可以放心写**：简化不改变结论方向（如数据通路上的累积效应可忽略——窗口太短）；
- **哪些假设必须加限定条件**：简化在特定条件下才成立（如跨级故障独立恢复——均匀采样下可用，边界区域失效）；
- **哪些假设不能写**：简化与物理事实矛盾（如默认布局下"每级最多一个错误"——\(\eta<1\)，需布局干预才成立）。

§3 的适用范围表就是这个判断力的第一次系统化。每条假设标注为已验证、部分验证或纯假设。写论文时回头看这张表，就知道每句话的底气有多足。

## 1. 核心命题

### 1.1 主命题

对于采用 per-stage 符号级纠错码（如 [6,4,3] 算术码）的流水数据通路，单次粒子打击的可纠正性由两个独立条件的**合取**决定：

$$
\text{可纠正} = \underbrace{(\text{翻转符号数} \leq \lfloor(d_{\min}-1)/2\rfloor)}_{\text{编码条件（代数）}} \;\wedge\; \underbrace{(\text{被核覆盖的异符号数} \leq 1)}_{\text{几何条件（物理）}}
$$

编码条件由码的最小距离保证，与布局无关。几何条件由布局决定，与码无关。**默认 FPGA 布局不保证几何条件成立**——平台测量（WP9）已观察到默认布局下同码字多符号事件。

### 1.2 临界核直径

定义符号感知隔离比：

$$
\eta = \frac{d_{\min}(\text{同码字、异符号的 Site 集合})}{D_{\text{kernel}}(\text{LET}, \theta)}
$$

其中 \(D_{\text{kernel}}\) 是打击核在斜入射角 \(\theta\) 下的有效直径（含 \(1/\cos\theta\) 拉伸）。

- \(\eta > 1\)：单次打击**几何上不可能**覆盖同一码字的两个符号 → 编码条件被物理条件保护，per-stage ECC 的代数保证在空间相关故障下仍然成立。
- \(\eta \leq 1\)：存在打击位置和角度的组合使两个符号同时被覆盖 → 可能出现 DUE。

**布局干预的目标**：通过符号感知布局（L3）将 \(\eta\) 从默认布局的 \(<1\) 提升至 \(>1\)，代价为布线资源和时序。

### 1.3 非正式表述

> Per-stage ECC 的纠错能力上限，不是由码的最小距离决定的，而是由保护域的物理间距与打击核尺寸的比值决定的。码给了你纠一个符号的代数能力，布局决定这个能力在粒子打击下是否兑现。

## 3. 适用范围与显式边界

### 3.1 结论适用域

| 域 | 覆盖？ | 说明 |
|---|---|---|
| FF 状态位 | 是 | 符号隔离直接有效 |
| BRAM 数据位 | 是 | 同上 |
| DSP 状态位 | 是 | 同上 |
| CFG — LUT INIT | 部分 | 属于符号内的逻辑，间距隔离间接降低同码字多符号，但语义为结构改变 |
| CFG — 布线 PIP | **否** | 布线跨区域，PIP 翻转改拓扑不改数值，ECC 纠不了「线断了」；需要 scrub / 布线 TMR |
| SET（走线瞬态） | **否** | 平台明确排除；走线本身不存状态，瞬态脉冲沿线传播 |
| 累积多事件 | **否** | 两次独立打击在空间上无关联，是解析问题（泊松卷积），不是布局问题 |

### 3.2 已声明的假设

| 假设 | 标注 | 来源 |
|---|---|---|
| RPM 格 → µm 换算 | `assumption:` 区间 4–16 µm，名义 8 µm | WP8 `units.py` |
| 中子能量 → LET 桥 | `assumption:` 显式公式，非静默换算 | WP8 `units.py` |
| 椭圆核 = MBU 图案的粗粒度代理 | 文献标准做法 | Ebrahimi DAC'13 / TCAD'16 |

## 4. 与现有文献的关系

| 文献线索 | 做了什么 | 本文的差异 |
|---|---|---|
| SRAM bit interleaving（Martin 1987 等） | 拆开同一字的相邻 bit | 本文拆的是**算术码符号**（功能粒度），且同一符号内部可以聚拢 |
| TMR 布局隔离（Sterpone, Wirthlin 等） | 拉开三模副本 | 本文保护单元是**码字内符号**，不是模块副本 |
| 标准单元 MET 间距（Ebrahimi, Georgakidis 等） | 拉开 ASIC 标准单元 | 本文在 **FPGA** 上，约束是 pblock/RPM，不是绝对坐标 |
| 布局→SER 估计（Ebrahimi, Kiddie 等） | 估计软错误率 | 本文估计的是**ECC 结局类别**（CORRECTED/DUE/SDC/MASKED），并与码字边界绑定 |
| CRAM↔功能映射（Mao, X-Ray 等） | 打通映射链路 | 映射是本文的**工具**，不是贡献 |

## 6. 方法论贡献（独立于主命题）

**质心伪影**（WP3/WP4 发现）：在布局感知故障仿真中，将打击中心固定在布局质心（或任何与边界相关的特征点）会系统性高估跨域故障率。正确的采样分布必须显式声明，且应在占用区域内均匀采样。这条教训适用于所有基于椭圆核的布局仿真，不限于本平台。

## 7. 下一篇论文的一句话故事

> 我们用 per-stage ECC 保护了一个 FFT 处理器（TCAS 论文），但纠错码的代数保证有一个隐含前提：同一码字的符号不能被一次打击同时摧毁。本文量化了这个前提在 FPGA 布局下的成立条件（\(\eta\)），证明默认布局不满足它，并提出符号感知布局使其成立，代价仅为可接受的布线开销。
