离子打中之后，LUT / FF / BRAM 里到底翻了什么

示意电路 · 不是版图级网表

三种资源共用同一套双稳态

7 系列里 LUT 真值表、FF 的 Q、BRAM 的每一个数据位，底层都是两个反相器首尾相咬的 SRAM/锁存单元。稳定态只有 0 和 1。所谓翻转，就是这个咬合被外电荷推过再生点，自己锁到另一边。

这是 CREME 时代的有效 LET 图像，不是 3D 收集体积仿真。7 系列 28 nm SRAM 的 Qcrit 很小，所以低 LET 的 H/He 也能翻（Lee 2014 的 Lth 只有 0.1–1.1 MeV·cm²/mg）。

和打击器四个域怎么对应

LUT 真值表属于 CFG / CRAM。写进 bitstream，一直保持到回读/纠错/重配。
FF 的 Q属于 FF_STATE。用户状态，时钟沿可以覆盖，使能关掉就一直错。
BRAM 阵列属于 BRAM_STATE。数据，写端口或 scrub 才能改回来。
DSP 流水寄存器属于 DSP_STATE，电路更像 FF。Lee 2014 没有 DSP 截面，次数表未计入。

还没画进这页、但芯片里也有的

  • 互连 PIPs / 开关盒：同样是 CRAM SRAM，翻了会改连线，功能错得更「像短路」。打击器里并进 CFG。
  • LUT 输出后面的那颗 FF：那是 FF_STATE，不是 LUT SRAM。
  • BRAM 的模式位、级联位：那是 CRAM，不是阵列数据。

LUT 电路：SRAM 真值表 + 输入选择的多路器

7 系列 Slice 里是 LUT6：64 bit 配置 SRAM + 64 选 1 的树形 mux，输入 A5…A0 当地址去读那一位。下面用 LUT3（8 bit） 把同一件事画清楚——真实芯片只是格子从 8 变成 64。

点格子 = 选中要打的 SRAM 单元。这不是用户数据，是配置位：功能本身被改写。

这一击之后发生什么

和「BRAM 翻转」的差别

  • LUT SRAM 在上电配置时写入，运行中通常不再写。翻了就一直是错函数，直到 SEM/回读纠正或重新加载 bitstream。
  • 只有地址恰好等于被翻那一格时，O6 才错；其它输入组合仍对。所以看起来像「某组输入下偶发组合逻辑错误」。
  • 若 LUT 配成 SRL/分布式 RAM，格子变成用户数据，机制仍是 SRAM 单元翻转，只是语义从 CFG 变成了类似 BRAM。

FF 电路：主从 D 触发器（两级锁存）

7 系列 Slice 有 8 个 FF，常用原语是 FDRE：D、时钟、时钟使能 CE、同步复位。存储发生在从锁存器的交叉耦合节点上，不是「线被打断」。

这一击之后发生什么

电路上「怎么反转」

  • 从锁存器关态漏极收集电荷 → Q 节点电压越过再生点 → 两个反相器把 Q/Qb 对调。Q 引脚立刻变反。
  • CE=1：下一有效时钟沿会把当前 D 写进从锁存器。若组合逻辑还在送正确的 D，FF 自己恢复。
  • CE=0（保持）：没有采样，错误一直停在 Q 上，直到使能再次打开。状态机、计数器最怕这种。
  • 若离子只在组合逻辑上打出窄脉冲（SET），脉冲被时钟采进 FF，看起来也像 FF 翻了——源头不是 FF 单元本身。

BRAM 电路：字线/位线 + 6T SRAM 阵列

Virtex-7 的 RAMB36 是真双口 SRAM 阵列（36 Kb）。每一个数据位仍是 6 管单元：两个反相器 + 两个字线控制的传输管。点阵列中的一格 = 打中那一颗存储单元。

示意阵列 4 字 × 8 bit。真实 RAMB36 按模式可以是 32K×1 … 512×72。

这一击之后发生什么

和 LUT / FF 的差别

  • 怎么翻：6T 单元被收集电荷推过再生点，那一格的 0/1 对调。位线只在读周期才接上去，所以静止时也照样能翻（漏极仍在）。
  • 用户看见什么：只有读到那个地址时，对应比特才错。没读到就暂时「看不见」，但位已经错了。
  • 怎么回来：写端口覆盖、ECC 纠错写回、或配置帧 scrub（那是 CRAM，不是阵列）。空等时钟不会像 FF 那样自动恢复。
  • 7 系列 BRAM 可开 64+8 SECDED。单位翻转能纠；MCU 翻多位就可能 DUE。次数表里的 BRAM 率是 bit 翻转，还没有走到这一层。

横截面不是 LUT/BRAM 在芯片上占的那一块

Lee 2014 的饱和截面 σsat 是打中就会翻的灵敏面积（高 LET 下 ≈ 关态漏极收集区），单位是 每个 bit。LUT 那一格、RAMB36 那一整块，是很多个单元铺出来的几何外壳，比灵敏区大两到三个数量级。

数字：σsat 来自 Lee REDW 2014 Table 1（JSON 里的 cm²/bit）。28 nm 6T SRAM 单元 0.127 µm² 是 TSMC 同代高密度 SRAM 的公开数字（VLSI 2009 / EE Times），用来当「一个存储单元有多大」的尺子，不是 Xilinx 公布的 CRAM 版图。1 RPM 格 = Y 向 22.8 µm（X 向 CLB 内 8.6 µm、跨列非均匀）是 2026-08-22 用 UG475 v1.9 官方 die 尺寸 × Project X-Ray 栅格数标定的，见 data/rpm_grid_calibration.json。

同一把尺子：一个 SRAM 单元 vs 三块灵敏区

把 0.127 µm² 的 6T 单元画成大方块。红/绿/蓝小块是 σsat 按面积开方后的边长，三者同一比例。

6T 单元 0.127 µm²（边长 356 nm） CRAM/LUT bit 18 nm BRAM bit 20 nm FF bit 38 nm

为啥觉得「那么大」

  • 科学计数法骗人。 3.34×10−12 cm²/bit 看起来像实验室大数，开方只有 18 nm，就是一只漏极。28 nm 工艺下这是对的量级。
  • FF 比 SRAM 大约 4 倍（1.47×10−11 / 3.34×10−12 = 4.4）。触发器管子、漏区比 6T SRAM 大，不是 Slice 画得更大。
  • LUT 和 BRAM 的 bit 几乎一样大（18 nm vs 20 nm）。BRAM「块头大」是因为一块 RAMB36 里有 36 Kb 个这样的小单元，不是每个 bit 像砖头。
  • 整片次数大是因为 bit 多。 vx690t 约 2.30 亿 CRAM × 每 bit 18 nm 级灵敏区。单 bit 并不大。
