打击参数

Lee σ 配 anchored 核时翻转很少、甚至候选为 0，是物理结果（核半径 < 1 格），不是坏了。a0 / k_LET 只在 legacy 核下生效。

布局坐标 = P1 OOC 布局 DCP（Vivado 2018.3，xc7vx690tffg1761-2）导出的 Site 栅格； anchored 核面积 A(LET) = Radaelli 2005 SRAM MBU 面积幂律（Ebrahimi DAC'13 Table 1，α≈0.70，能量→LET 桥为显式假设）； a0 / k_LET 为几何调试参数，无物理出处。

故障域（指南第 8 节）

同一 Site 在同一 (x,y) 上叠加多个故障域；同一个椭圆对每个域各求一次交， 跨域相关性因此保留。勾选只影响黄/红标记的显示，计算始终覆盖全部域。

每域位数：CFG 2122 bits/slice ← UG470 Table 1-1 bitstream 229,878,496 ÷ DS180 slices 108,300（均摊，非 essential bits）； BRAM 36,864 ← UG473 RAMB36E1（36 Kb）；FF ← 布局 FD*/LD* 实例（器件总量 866,400 ← UG474/DS180，8 FF/slice）； DSP 169 ← UG479 DSP48E1 数据通路寄存器——无实测 σ（Lee Table 1 无 DSP 行），weibull 模式永不翻转 DSP。

着色

级/角色标签 = WP1 层次名解析（unknown role 占 0.02%）；级色为 HSV 色带，仅用于区分。

格子含义

整片是 P1 在 xc7vx690t 上占用包围盒里的 Site 栅格（RPM 坐标）。
暗格 = 包围盒内空闲
黄 = 椭圆候选（域×Site）　 红 = 抽样翻转
一格是一个 FPGA Site；悬停显示 stage / role / 域位占位。

网格→物理尺寸：1 格 = Y 向 22.79 µm / X 向 8.63 µm（CLB 内，跨列非均匀）——2026-08-22 由 UG475 v1.9 官方 die 尺寸 × Project X-Ray 栅格数标定（tile 行 45.58 µm、列 34.53 µm）， 详见 data/rpm_grid_calibration.json（含 UG475 SHA-256 与 K325T 独立验证）。

几何用例（指南 9.3）

黄/红钉在 Site 上；拖拽转相机。俯视锁定后左键只平移。

资料来源总表（全部参数出处）
  1. 重离子 σ(LET) Weibull（CRAM/BRAM/FF 三域）：Lee, Wirthlin, Swift, Le, 2014 IEEE REDW, DOI 10.1109/REDW.2014.7004595，Table 1（σsat = A µm²/bit × 1e-8；DUT XC7K325T，28 nm 同族借用）。OSTI 全文公开。
  2. RPM 格 → µm：Xilinx UG475 v1.9《7 Series Packaging and Pinout》Chapter 4 官方 die 尺寸 × Project X-Ray tilegrid（K70T/A200T 双器件拟合，K325T 独立验证）→ data/rpm_grid_calibration.json。
  3. anchored 核面积 A(E)：Radaelli 2005（经 Ebrahimi DAC 2013 Table 1 转录，22/47/95/144 MeV → 1.178/1.902/2.903/4.613 µm²）；能量→LET 桥为平台显式假设。
  4. MBU P(k)（pattern 模型）：Pérez-Celis & Wirthlin, IEEE TNS 2021, DOI 10.1109/TNS.2021.3071704（SBU 70% / MCU 30%）；交叉验证：Wirthlin 2014 JINST 9 C01025 Table 2（65.0% / 26.8%）。
  5. 器件资源（slices/DSP/BRAM/FF）：AMD DS180 v2.6.1 Table 1（108,300 slices · 3,600 DSP · 52,920 Kb BRAM · 8 FF/slice）；UG470 Table 1-1（bitstream 229,878,496）；UG473（RAMB36E1）；UG479（DSP48E1）。
  6. 中子锚点（校验用，不进重离子核）：AMD UG116 v10.20（2025-07-23）28 nm 行 CRAM 5.69e-15 / BRAM 5.57e-15 cm²/bit；独立实测 Wirthlin 2014 JINST Table 1（LANSCE 6.89e-15/6.15e-15）差 ≤21%，交叉校验通过（2026-08-22）。
  7. 质子 σ(E)（存表未接线）：Wirthlin, Takai, Harding, 2014 JINST 9 C01025, DOI 10.1088/1748-0221/9/01/C01025，Table 1（TSL 180 MeV 质子 CRAM 8.29e-15 / BRAM 8.19e-15）。
  8. 布局数据：P1 OOC 布线 DCP（Vivado 2018.3）导出 primitive_map.csv，24,446 Site / 140,907 原语；共享 Site 2.5%。
  9. 已知缺口（不编造）：DSP48E1 无公开 σ（Lee 无 / UG116 无 / NEPP 测的是 RTG4）；FF 无厂商中子 σ；essential bits 需 bitstream/SEM。详见 handover/审计_假设值真实化_20260822.md。
