垂直截止刚度沿轨道

横轴：沿轨道飞行时间 t（分钟），从本圈采样起点算。
纵轴：垂直截止刚度 Rc（GV）——地磁门口的刚性门槛；粒子磁刚度低于 Rc 进不来。
计算（倾斜中心偶极 Størmer）： Rc = Rc,eq · (RE/r)2 · cos4λm 。Rc,eq 取左侧表单「赤道截止 GV」（默认 14.9 GV）， r 为地心距，λm 为磁纬。Rc 高＝屏蔽强（赤道、低轨）；Rc 低＝弱屏蔽（高纬、高轨道）。 偶极近似相对多极截止图约 ±20%。点「计算」后出曲线。

图例与依据
轨道颜色 = 该处地磁截止刚度（中心偶极 Størmer，与计算用的同一公式）：红 = 屏蔽弱，宇宙线容易进来。
宇宙线：每个粒子有自己的刚度，低于当地截止刚度就被磁场挡回（示意）。
辐射带：粒子沿偏心偶极磁力线弹跳、质子西漂、电子东漂；只表示位置与运动方式，通量需 AP8/AP9、AE8/AE9。
SAA：IGRF 前两阶在 500 km 高度 |B| < 23 000 nT 的区域。
卫星处红圈 = 按算出的器件平均翻转率抽样到一次 SEU（时间加速）。拖拽旋转、滚轮缩放、单击轨道定位、双击复位。地表：NASA Blue Marble。
