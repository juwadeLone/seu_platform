## 3. 故障模型与分类

每一枪翻转 **一个** 已接收符号的 **一个** 分量的 **一位**（校正器之前）：

```
(Stage 1–7 + Stage 10) × 6 符号 × 2 分量 × 35 bit = 3360
```

对照实例是清洁 `top_p1_pfft_ecc`、同一激励、无翻转。分类与 S3 TB 相同。

| 类别 | 条件（相对无故障输出） |
|---|---|
| `corrected` | 输出逐拍相等，且 DUT `detected && corrected` |
| `silent_bounded_residual` | 输出相等，且全程未举手 |
| `silent_unbounded` | 输出不相等，且全程未举手 |
| `detected_only` | 输出不相等，举手但未纠正 |
| `miscorrection` | 输出不相等，却报告已纠正 |

TB 的 `recovery_rate` = (corrected + silent_bounded) / N，即 Gao 口径。

硬件举手：综合征分量 **|sy| > τ** 才当故障。τ=3 时 **|sy|≤3 一律当噪声**。单 bit 翻转产生 |sy|∈{1,2,4,…}，因此 bit 0（|sy|=1）与 bit 1（|sy|=2）被吸收；bit ≥ 2（|sy|≥4）应举手。

按符号（每格 560 枪；Gao% = (corrected+bounded)/560）：

每个符号 corrected 都是 528 = 560−32。32 = 8 个 ECC 级（1–7 与 10）× 2 分量 × {bit0, bit1}。

## 6. 未检出位点的结构

清单：`silent_sites.csv`（192 行）。规律：

- **bit 0** → |sy|=1 ≤ 3 → 不举手。
- **bit 1** → |sy|=2 ≤ 3 → 不举手。
- **bit ≥ 2** → |sy|≥4 > 3 → 举手并纠正。

因此漏检都在阈值之内，是 Gao 门限的预期吸收，不是大门限外的漏译。τ=3 比 S3 的 τ=2 多吸收 |sy|=3，但单 bit 翻转不会产生 |sy|=3，所以 silent 位集合仍是 bit{0,1}。

未举手之后，残差是否仍 bit-exact **按符号角色整块分开**（8 级一律相同，不像 S3 那样随 Stage 2 混杂）：

| 符号 | bounded | unbounded | 行为 |
|---|---:|---:|---|
| 0–3（功能） | 0 | 32 | 8 级 LSB 全 unbounded |
| 4–5（校验） | 32 | 0 | 8 级 LSB 全 bounded |

“未举手”由 |sy|≤τ 决定；“残差是否被后级放大”看放过的 LSB 走完 PFFT 后顶层输出还能否对上。本枪里功能符号 LSB 一律对不上，校验符号 LSB 一律对得上。
