## 1. 为什么跑这一枪

作者确认：

- 阈值用 **Gao 2023 的 3σ**，不是 Gao 2016 经验 τ=1。标定包 `s3_gao2023_threshold_v1_001` 给出 `ceil(3σ)≈1.72 → τ=2`。

## 3. 故障模型与分类（TB 行为）

每一枪翻转 **一个** 已接收符号的 **一个** 分量的 **一位**（upper 分支，frame 0、`out_count==8`，算术校正器之前）：

```
8 级 × 6 符号 × 2 分量（real/imag）× 35 bit = 3360
```

对照实例是同一 DUT、同一激励、无翻转。监视故障实例的顶层输出，直到一帧结束。

| 类别 | 条件（相对无故障输出） |
|---|---|
| `corrected` | 输出逐拍相等，且 DUT `detected && corrected` |
| `silent_bounded_residual` | 输出相等，且全程未举手（`!detected`） |
| `silent_unbounded` | 输出不相等，且全程未举手 |
| `detected_only` | 输出不相等，举手但未纠正 |
| `miscorrection` | 输出不相等，却报告已纠正 |
| `corrected_no_flag` | 输出相等，举手但 `corrected=0` |

TB 的 `recovery_rate` = (corrected + silent_bounded) / N，即 Gao 口径：门限内、输出仍 bit-exact 的 silent 算“可接受残差”，不算检出。

硬件举手判据：综合征分量 **|sy| > τ** 才当故障。τ=2 时 **|sy|≤2 一律当噪声**。

**未检出 = 192**（106+86）。这 192 枪 **全部是 bit 0 或 bit 1**。bit≥2 的 3168 枪全部 `corrected`。

按符号（每格 560 枪；Gao% = (corrected+bounded)/560）：

| 符号 | 角色 | corrected | bounded | unbounded | Gao% |
|---|---|---:|---:|---:|---:|
| 0 | 功能 | 528 | 28 | 4 | 99.29 |
| 1 | 功能 | 528 | 14 | 18 | 96.79 |
| 2 | 功能 | 528 | 0 | 32 | 94.29 |
| 3 | 功能 | 528 | 0 | 32 | 94.29 |
| 4 | 校验 | 528 | 32 | 0 | 100.00 |

每个符号 corrected 都是 528 = 560−32。32 = 8 级 × 2 分量 × {bit0, bit1}。

## 6. 未检出位点的结构（实验行为）

清单：`silent_sites.csv`（192 行）。规律：

- **bit 0** 对应 |sy|=1 ≤ 2 → 不举手。
- **bit 1** 对应 |sy|=2 ≤ 2 → 不举手。
- **bit ≥ 2** 对应 |sy|≥4 > 2 → 举手并纠正。

因此：**漏检都在阈值之内**，是 Gao 门限的预期吸收，不是大门限外的漏译。

未举手之后，残差是否仍 bit-exact 随符号/级而变：

| 符号 | bounded | unbounded | 行为 |
|---|---:|---:|---|
| 0 | 28 | 4 | 仅 Stage 2 的 4 个 LSB unbounded；其余 7 级 LSB bounded |
| 1 | 14 | 18 | Stage 2 四个 LSB 全 unbounded；其余 7 级 real LSB unbounded、imag LSB bounded |
| 2、3 | 0 | 32 | 8 级 LSB 全 unbounded |
| 4、5 | 32 | 0 | 8 级 LSB 全 bounded |

Stage 2 对功能符号 0–3 的 LSB 一律无界。校验符号 4–5 的 LSB 一律有界。

“未举手”和“残差是否被后级放大”是两件事：前者由 |sy|≤τ 决定；后者看放过的 LSB 误差在 SDF 里走完后顶层输出还能否对上。
