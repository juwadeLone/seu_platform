# SC-01 阈值推导报告

## 1. 目的

为回应审稿人 R1-M1/SC-01，需要在 Python 仿真中实现 Gao 阈值检测逻辑，重跑恢复率实验。

## 2. 方法

### 2.1 诊断扫描

对 S3 的 8 个 arithmetic stages × 4 positions × 6 symbols × 2 components × 35 bits = **13,440 个试验**进行全扫描：

1. 先捕获无故障时的 compensated syndrome（expected_residual）
2. 对每个单 bit 翻转，计算 compensated syndrome 各分量
3. 记录 max(|sy0_real|, |sy0_imag|, |sy1_real|, |sy1_imag|) 的分布

### 2.2 关键发现

| 指标 | 值 |
|------|-----|
| 无故障残差最大值 | **0** |
| 零 syndrome 计数 | **0** (0%) |
| 非零 syndrome 计数 | **13,440** (100%) |
| 最小非零 syndrome | **1** (bit 0 翻转) |
| 最大 syndrome | 17,179,869,184 (bit 34 翻转) |

### 2.3 Syndrome 分布

syndrome 幅值呈 2 的幂次分布，每个值恰好出现 384 次：

| 幅值 | 计数 | 对应 bit |
|------|------|----------|
| 1 | 384 | bit 0 |
| 2 | 384 | bit 1 |
| 4 | 384 | bit 2 |
| 8 | 384 | bit 3 |
| 16 | 384 | bit 4 |
| 32 | 384 | bit 5 |
| 64 | 384 | bit 6 |
| ... | ... | ... |
| 2^34 | 384 | bit 34 |

## 3. 阈值推导

### 3.1 Gao 原则

Gao 2016 的阈值 τ 是"无故障定点残差的最大值"，低于此值的被认为是可接受的定点误差。

### 3.2 本模型的阈值

由于 Python 仿真使用**精确整数运算**（无定点截断），无故障残差恰好为 0。因此：

- **阈值下界** = 无故障残差最大值 = **0**
- **阈值上界** = 最小非零 syndrome = **1**
- **选定阈值** = **0**（Gao 原则：取无故障残差最大值）

### 3.3 与 Gao 原文的对比

| 要素 | Gao 2016 | 本论文 Python 模型 |
|------|----------|-------------------|
| 数据宽度 | 12-16 bit | 35 bit (data) / 39 bit (check) |
| 定点截断 | 有（12→14→16 bit 截断） | 无（精确整数） |
| 无故障残差 | 非零（定点截断导致） | **0**（无截断） |
| 阈值 τ | 1 | **0** |
| 效果 | 低于 τ=1 的故障被吸收 | 所有故障 syndrome ≥ 1 > τ=0，全部检测 |

### 3.4 关键洞察

**Python 仿真是精确整数模型，不存在定点截断残差。** 无故障 compensated syndrome 恰好为 (0, 0)，因此阈值 τ=0 就是最严格的 Gao 阈值——任何非零 syndrome 都是真实故障。

论文中报告的 92.4% 恢复率和 39 个 zero-syndrome 漏检、14 个检测但不可纠正，反映的是 **RTL 硬件实现中的定点截断效应**，不是 Python 精确整数模型能复现的。

## 4. 阈值=1 的对比实验

为展示阈值的影响，也用 τ=1 运行了对比实验：

| 阈值 | S3 corrected | S3 silent | S3 miscorrection | S3 Gao PASS |
|------|-------------|-----------|-----------------|-------------|
| 0 | 3360 (100%) | 0 | 0 | 100% |
| 1 | 3264 (97.14%) | 96 (2.86%) | 0 | 100% |

τ=1 时，96 个低位翻转（bit 0 在某些 symbol/component 组合下产生 |syndrome|=1）被吸收为"可接受残差"，不再检测纠正。但 Gao 式 PASS 仍为 100%。

## 5. 结论

- Python 精确整数模型中，Gao 阈值 τ=0 是正确阈值
- 该阈值下所有单 bit 故障 100% 检测并纠正，miscorrection = 0
- 论文 92.4% 反映的是 RTL 定点截断效应，需在 RTL 仿真或门级模型中复现
- Gao 式 PASS（含 silent bounded residual）在 τ=0 和 τ=1 下均为 100%
