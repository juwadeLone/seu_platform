# SC-01 方案B 阈值推导报告（threshold_selection.md）

> **日期**：2026-08-10
> **依据**：`sc01_b0_residual_tb.sv` 零注入扫描（10 帧 × 256 beats × 8 stages × 2 boundaries = 40960 样本）

## 1. 无故障 raw syndrome 残差上界 M

扫描原版 S3（零注入）所有 ECC stage 的 raw syndrome（`arithmetic_boundary_from_clean_v5`
内 `res0r/res0i/res1r/res1i`，无故障时即码字自校验残差 ρ）：

| 指标 | 值 |
|------|----|
| 有效样本数 | 37,318（3,642 个 x 为流水未填满的无效拍，已剔除） |
| **M = max \|ρ 分量\|** | **6** |
| M 出现位置 | stage 1 lower boundary（beat 1573） |
| 分 stage 上界 | s1–s6: 6；s7–s8: 2 |
| ρ=0 样本占比 | 28,705 / 37,318 = **76.92%** |
| \|ρ\| 分布 | 1→10,879；2→5,440；3→973；4→287；5→100；6→22 |

**解读**：
- 无故障残差上界 M=6，为个位数，与方案 B 预期一致（每路径 `>>>1` 残差 ∈{0,1}，
  twiddle Q2.28 截断 <1 LSB，syndrome 为 5 路输出组合）
- 76.92% 的码字残差恰为零（bit-exact 率上限）
- 残差最大值出现在早期 stage（s1–s6），随 stage 递减（s7–s8 上界仅 2）

## 2. τ 选定

**Gao 原则**：τ = 无故障残差上界 M = 6。

**硬件友好修正**：M=6 非 2 的幂。取 **τ = 8**（2³）：

- 比较器为 3-bit 位宽，无常数比较的额外开销
- τ=8 ≥ M=6，保证无故障时不误检（|ρ| ≤ 6 < 8）
- 模式匹配容差 **TOL = 2×τ = 16**

| 量 | 值 | 说明 |
|----|----|------|
| M（实测残差上界） | 6 | 零注入扫描 |
| **τ（检测阈值）** | **8** | 2 的幂，≥ M |
| TOL（模式匹配容差） | 16 | 2×τ |

## 3. 预期恢复率推算

单 bit 翻转产生 syndrome 增量 m(δ) = ±2^k（k=0..34）。检测判据 |ρ + m(δ)| > τ：

- k ≥ 4（效应 ≥16 > τ+ M 余量）：必检测
- k = 3（效应 8）：|ρ + 8| > 8 当 ρ > 0 或 ρ < −16（多数情况检测；ρ=−8 恰好临界）
- k = 0..2（效应 1,2,4 ≤ τ）：通常被阈值吸收 → **漏检**

粗估检测恢复率 ≈ (35−3)/35 ≈ 91%，**与论文旧数字 92.4% 同量级**——预期互相印证。
