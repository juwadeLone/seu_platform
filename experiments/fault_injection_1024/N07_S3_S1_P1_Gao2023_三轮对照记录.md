## 1. 两步流程（三轮相同）

```
K_* 无故障 10 帧 ──► 采 raw 综合征 CSV ──► Python 3σ ──► τ=ceil(3σ)
        │                                      │
        │ bit-exact 2048/2048 必须 PASS         │ Th=0 则停，询问
        ▼                                      ▼
  隔离 thresholded iverilog DUT + 注入 TB ──► 单 bit XOR ──► 四分类
```

**混合口径（必须分开说）：**

- **阈值**来自仓库外 fair kernel `K_S3` / `K_S1` / `K_P1` 的无故障 raw 综合征（现网 `THRESHOLD` 仍在源码里，这三份标定迹上 `found=0`）。
- **注入**跑的是 tcas 仓里的 **thresholded 副本**：把 `|sy| > τ` 写进校正器，并加 XOR 钩子。τ **没有**写回 `K_*`。
- 因此本记录回答的是：「用 Gao 2023 的 3σ 整数门限，在隔离 iverilog DUT 上单 bit 翻转能否恢复」；**不是**「现网 THRESHOLD=4/16/8 的 K_* 源码 5040/… 枪」。

## 2. 阈值怎么算（Gao 2023 → 本实验）

Gao 2023（TCAS-I channelizer）把浮点对照得到的量化噪声 σ 传到检查量，再取 \(T_h=3\sigma\) 的整数。本实验的对应物：

| Gao 2023 | 本三轮 |
|---|---|
| Matlab 浮点 vs FPGA 定点，得输出量化噪声 σ | 无注入下，译码器所见 **raw 综合征**（检查量本身） |
| 式 (17) 把噪声方差传到 Δ1/Δ2 | 不另传：综合征已经是检查量 |
| \(T_{h1}=3\sigma(\Delta_1)\)，取整数 | \(\tau=\mathrm{ceil}(3\sigma_{\max})\) |
| 硬件比较 | \(\lvert sy\rvert > \tau\)（**严格大于**；\(\lvert sy\rvert=\tau\) 当噪声） |
| 无故障虚警 | 同一 10 帧标定集上「任一分量 \|sy\| > τ」的比例（不是 \(10^{11}\) 板上虚警） |

对照：2026-08-10 `uncomp_v1_001` 的 S3 τ=4 是 \(M=\max\lvert\rho\rvert=3\) 再取 2 的幂，**不是** 3σ。

### 2.1 标定 TB 做什么

三份噪声底板 TB 结构相同，只换 DUT 和采样探针：

| | S3 | S1 | P1 |
|---|---|---|---|
| TB | `results/s3_gao2023_threshold_v1_001/tb_s3_gao2023_noise_floor.sv` | `.../s1_.../tb_s1_gao2023_noise_floor.sv` | `.../p1_.../tb_p1_gao2023_noise_floor.sv` |
| 输入 | `kernels/S3/vectors/qualification_input_10frames.hex`（2560 beat） | S1 同名 hex | P1 同名 hex |
| 金标准 | `qualification_subfft_expected_8frames.hex`（2048 beat） | 同左 | `qualification_pfft_expected_8frames.hex` |
| 采样条件 | 每级 `dut.u.s{k}.syn_v` | `dut.pv_d3` | Stage 1–7：`syn_v`；Stage 10：`go_syn` 上的 `sy0_ur,...` |
| CSV | `cycle,stage,sy0r,sy0i,sy1r,sy1i,found` | `...,syn0r/i,syn1r/i,syn2r/i,found` | 与 S3 同列，stage∈{1..7,10} |

时钟：`always #5 clk=~clk`。复位后按拍送 2560 beat，`in_last` 每 256 beat 拉一次。`out_valid` 上与 expected hex **逐 beat 比较**；mismatch>0 则 **不给出 τ**。三轮都是 `PASS bitexact` 2048/2048。

命令：

```bash
bash experiments/fault_injection_1024/results/s3_gao2023_threshold_v1_001/run_calibrate.sh
python3 experiments/fault_injection_1024/results/s3_gao2023_threshold_v1_001/analyze_3sigma.py
# S1 / P1 同结构，目录换成 s1_ / p1_
```

### 2.2 Python 公式（三轮同一 `analyze_3sigma.py`）

对 CSV 里每个综合征分量（有符号整数）：

1. 样本均值 `statistics.fmean`
2. **样本标准差** `statistics.stdev`（\(n-1\)，ddof=1），对象是 **有符号 sy 本身**，不是 `|sy|`
3. 全级合并后取四分（或六分）量里最大的 σ，记 σ_max
4. \(3\sigma = 3\cdot\sigma_{\max}\)
5. **采用** \(\tau=\lceil 3\sigma-10^{-12}\rceil\)；四舍五入只并列报告，**注入不用**
6. 若 τ=0：与「定点必须有阈值」冲突，停止询问。本三轮 τ 均 >0。

虚警：

\[
\mathrm{FA}=\frac{\#\{\text{样本}:\ \exists c,\ \lvert sy_c\rvert>\tau\}}{N_{\text{样本}}}
\]

S3 还报了 L∞ 直方图：0→13898，1→1352，2→1369，3→300。故 τ=2 会把 300 个 `|sy|=3` 的无故障样本当故障（这就是「虚警先跑」的来源）。P1/S1 同样 τ < M。

### 2.3 硬件里 τ 怎么用

隔离 DUT 的校正器把分量 `|sy| ≤ τ` 当 0。S3/P1 的 `[6,4,3]` 校正器（`arithmetic_corrector_643_thresholded`）：

```verilog
th = THRESHOLD;
if ((abs39(sy0r)>th) || (abs39(sy0i)>th) || (abs39(sy1r)>th) || (abs39(sy1i)>th)) begin
  detected = 1;
  // 再用 |关系式| ≤ th 在 6 个符号位置里选 loc，然后减错误图样
end
```

S1 的 `[7,4,3]`（`gao_corrector_743_thresholded`）对 `s0,s1,s2` 六分量做同样的 `|·|>th` 才 `detected`。

单 bit 翻转在 syndome 上近似给出 `|sy| = 2^{bit}`（Q 格式下 bit0→1，bit1→2，bit2→4，…）。因此：

| τ | 被吸收的 bit（不举手） | 会举手的 bit |
|---|---|---|
| 2（S3） | 0（1）、1（2） | ≥2（≥4） |
| 3（P1） | 仍是 0、1（单 bit 不会产生 \|sy\|=3） | ≥2 |
| 5（S1） | 0、1、2（1、2、4） | ≥3（≥8） |

这与三轮 silent 位点完全一致。

## 3. 注入 TB 的公共骨架

三份注入 TB 都是 **双实例**：清洁对照 + 带钩子的故障实例，同一激励。每枪：复位 → 送 512 beat → 在窗口内拉一拍 `inject_enable` → 采样该级/该译码器的 `detected/corrected` → 关掉注入 → 监视顶层输出直到 `fault_last`。

激励一律：

`experiments/fault_injection_1024/common/vectors/qualification_input_10frames.hex`

TB 只读前 512 行（两帧 × 256 beat）。第二帧把 SDF 流水冲干净，并给出带 `out_last` 的整帧输出。

### 3.1 XOR 钩子（SV 在校正器之前翻 1 bit）

通用形式（S3 upper 分支为例，`protection_primitives_v5.sv`）：

```verilog
wire signed [34:0] up_inj_r =
  (inject_enable && (inject_symbol==g) && (inject_component==0))
    ? (upper_clean_r[g] ^ (35'sd1 << inject_bit))
    :  upper_clean_r[g];
```

残差始终用 **未翻转的 clean 符号** 算（`arithmetic_boundary_from_clean_v5_thresholded` / `gao_boundary_from_clean_v5_thresholded` 的第一组端口），received 口走 XOR 后的值。这样模拟的是「检查量仍按干净码字，数据路上多了 1 bit」。

| 架构 | XOR 写在哪 | `inject_symbol` 含义 |
|---|---|---|
| S3 | `independent_butterfly_ecc_v5_thresholded`：upper/lower 旋转后的 6 符号 | `[6,4,3]` 符号 0–5（0–3 功能，4–5 校验） |
| P1 | `p1_ecc_stage4_v3_thresholded`：旋转后 `rotated_*`；Stage 10 同结构 upper | 同上 0–5 |
| S1 | `top_s1_gao_subfft_ecc_thresholded`：7 条 `pathr/pathi` 出 lane 之后 | **路径** 0–6，不是逐级 6 符号 |

S3 本枪只在 **upper** 窗口注入（见下一节）；lower 钩子存在但 TB 不拉。

### 3.2 注入窗口（什么时刻拉 `inject_enable`）

每枪从复位开始，TB 在 `negedge clk` 上等窗口第一次为真，拉 **一拍** enable，下一拍采样 flag 后清零。

**S3**（`sc01_rtl_tb.sv` 的 `check_window`）：

```text
stage k ∈ 1..8 :  fault.u.s{k}.work_valid && fault.u.s{k}.work_second
```

即该级第一拍 **upper（second-phase）** 输出。深流水级若窗口出现在 512 beat 送完之后，用 `wait(check_window)` 兜底。

**P1**（`sc01_p1_rtl_tb.sv`）：

```text
stage 1..7 :  fault.u.s{k}.work_valid && fault.u.s{k}.work_second
stage 10   :  fault.u.s10.pair_phase == 1     // 蝶形执行拍
```

**S1**（`sc01_s1_rtl_tb.sv`）：

```text
fault.pv[0]   // 路径 0 的 lane 输出有效；7 条 lane 对齐，此时 XOR 打在选定路径 y
```

### 3.3 四分类（三轮 TB 同一套 if）

对照：顶层 4 路复数打包成 280 bit，`clean_word !== fault_word` 则 mismatch。

| 类别 | 输出 vs 清洁 | 该枪采样到的 flag |
|---|---|---|
| `corrected` | 相等 | `detected && corrected` |
| `silent_bounded_residual` | 相等 | `!detected` |
| `corrected_no_flag` | 相等 | `detected && !corrected`（本三轮 0） |
| `detected_only` | 不等 | `detected && !corrected` |
| `miscorrection` | 不等 | `corrected` |
| `silent_unbounded` | 不等 | `!detected` |

TB 打印的 `recovery_rate` = `(corrected + silent_bounded) / N`，即文中 **Gao 口径**：门限内、输出仍 bit-exact 的 silent 算可接受残差。

`detected` 只看 **被注入的那一级 / 那一个路径译码器** 在注入拍上的组合逻辑输出，不是「整帧里任何级曾举手」。

### 3.4 对照实例差异（写进记录以免混）

| | 清洁实例 | 故障实例 |
|---|---|---|
| S3 | 也是 `top_s3_subfft_ecc_thresholded #(.THRESHOLD(τ))`，但 `inject_enable=0` | 同模块，带 XOR |
| S1 | 原版 `top_s1_gao_subfft_ecc`（无 τ、无钩子） | 隔离 `top_s1_gao_subfft_ecc_thresholded` |
| P1 | 原版 `top_p1_pfft_ecc` | `top_p1_pfft_ecc_thresholded` |

S3 两边门限相同，比的是「有无这一拍 XOR」。S1/P1 比的是「无门限原版」vs「带 Gao τ 的 thresholded 副本」。

## 7. 三轮合在一起能说什么、不能说什么

能说（受控 iverilog、本激励、本故障模型）：

- 按 Gao 2023 把无故障综合征的 3σ 收成全局整数 τ 之后，单 bit 翻转的漏检 **全部落在 τ 吸收的低位**，不是大门限外的漏译。
- `[6,4,3]` 的 S3/P1 在 τ=2/3 下 silent 位集合相同（bit0/1）；S1 的 `[7,4,3]` 因 τ=5 多吸收 bit2。
- 未举手之后，残差是否还 bit-exact 是另一件事：S3 随级/符号混杂；P1 按功能/校验符号整块分开；S1 42 枪里 24 bounded + 18 unbounded。
- 有注入的这些枪 `miscorrection=0`、`detected_only=0`。

不能说：

- 不得把 3360 或 490 写成论文 **700**，也不得用 97.44% / 96.33% / 96.19% 覆盖 94.4%。
- `miscorrection=0` **不证明** 无故障帧在该 τ 下无虚警（三轮标定集虚警分别为 1.77% / 2.82% / 1.15%）。
- 不是 `K_*` 源码、不是现网 THRESHOLD=4/16/8、不是 D159 仍待确认的 K_S3 **5040** 枪。
- 未测 Yosys / Vivado / 板级 / 辐照；未注入 TMR 级。
