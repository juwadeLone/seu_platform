# 七个架构工程入口

这里按论文比较对象组织七个独立工程入口。每个目录给出架构定义、Python对象、RTL顶层、资源基线和冻结结果位置。

## SubFFT组

1. [`S0/`](S0/)：未保护SubFFT基线；
2. [`S1/`](S1/)：Gao完整路径ECC；
3. [`S2/`](S2/)：逐级完整TMR；
4. [`S3/`](S3/)：逐级ECC方案。

## PFFT组

1. [`P0/`](P0/)：未保护PFFT基线；
2. [`P1/`](P1/)：逐级ECC方案；
3. [`P2/`](P2/)：逐级完整TMR。

每个目录都有独立Python入口、RTL顶层、testbench、配置和结果目录。真正公共的实现位于`../common/`。
